Academic Final Year Project

DSE Stock Price Prediction Using HMM

Developed a machine learning-based stock price prediction system using Hidden Markov Models. Analyzed historical Dhaka Stock Exchange data using two different approaches.

Technologies Used

Python Gaussian HMM hmmlearn Pandas NumPy Matplotlib Flask

Project Overview

This project focuses on analyzing historical Dhaka Stock Exchange data and estimating stock price movements using Hidden Markov Models, a probabilistic machine learning technique.

Project Objective

To identify hidden market patterns from historical stock information and estimate stock price behavior using two different HMM-based approaches.

Approach 1: Price-Based Prediction

  • Used Open, High, Low and Close prices.
  • Calculated fractional price changes.
  • Extracted historical price movement patterns.
  • Applied Gaussian Hidden Markov Model.

Approach 2: Price and Volume-Based Prediction

  • Used closing prices and trading volume.
  • Calculated differences in closing prices.
  • Combined price changes with volume information.
  • Applied a second Gaussian HMM model.

Model Configuration

  • Algorithm: Gaussian Hidden Markov Model.
  • Number of hidden states: 4.
  • Covariance type: Full.
  • Maximum iterations: 10,000.
  • Tolerance: 0.001.
  • Two separate models were implemented.
